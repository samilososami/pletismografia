# Pletismografía experimental — Keyestudio ESP32 Plus

El proyecto Arduino está organizado dentro de [`tdr/`](tdr/). Para abrirlo en
Arduino IDE 2, abre directamente el archivo [`tdr/tdr.ino`](tdr/tdr.ino). Arduino
IDE cargará automáticamente los módulos incluidos en `tdr/src/`.

El prototipo utiliza una Keyestudio ESP32 Plus con un LDR y una LED roja para
obtener una señal PPG aproximada. Incluye calibración, cálculo experimental de
BPM, pantalla OLED, servidor web y respiración guiada 4–4.

> Prototipo educativo y experimental. No es un dispositivo médico.

Consulta [`tdr/README.md`](tdr/README.md) para la instalación, los pines y la
compilación.
